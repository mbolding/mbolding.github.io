Mermaid

How it works
  • tap select a node, then use the bar at the bottom
  • drag move a node, or pan the board from empty space
  • double tap edit a node, or add one on empty space
  • long press edit a node's text
  • pinch zoom, or use the + and − buttons
  • Link tap one node then another to connect them
  • Erase tap a node or a connection to remove it
  • wheel zoom at the pointer on a desktop
  • Enter edit the selected node
  • Tab cycle through nodes
  • Delete remove the selected node
  • Esc deselect, or cancel a pending link
  • arrows nudge the selected node
  • Ctrl/Cmd Z undo, with Shift to redo
  • right click arm a node, then right click another to link them
  • middle click delete a node outright
