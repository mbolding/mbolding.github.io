Student prompts
  1. Pick the smallest instrument set that distinguishes a 5-HT deficit from prone sleeping. Why does it work? Which node carries the distinguishing signal?
  2. Which node would you need to observe to test the hypothesis that a deficit blunts arousal specifically, rather than ventilation or gas exchange?
  3. Using fNIRS only, find a pair of scenarios whose cortical-HbO change has the opposite sign. What does that tell you about using ΔHbO alone as a biomarker?
  4. You can only add one instrument to fNIRS. Which single channel removes the most ambiguity, and what confound does it leave untouched?
